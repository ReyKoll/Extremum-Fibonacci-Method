# Поиск экстремума функции методом оптимизации Фибоначчи

Кроссплатформенное приложение (Windows / macOS / Linux): **C# + F# + Avalonia UI**, .NET 10.

**Приложение строит график одной из 4 функций:**

+ y = Sin(x)
+ y = Cos(x)
+ y = x² − 4
+ y = x − 2

и находит минимум/максимум методом Фибоначчи на заданном интервале [A; B].

## Числа Фибоначчи (F#)

```fsharp
module Fibonacci =
    let Get (n: int) : float = ...   // итеративно, O(n)
```

Числа Фибоначчи используются для сужения интервала неопределённости:
выбирается n, при котором F(n) ≥ (B − A)/ε, затем интервал последовательно
сжимается до длины ≤ ε, и середина финального интервала принимается за x*
экстремума (классическая схема метода Фибоначчи).

## Отличия от исходной WinForms-версии

### Кроссплатформенность
- WinForms + `System.Windows.Forms.DataVisualization.Chart` → **Avalonia 11**
  с собственным лёгким контролом `FunctionChart` (оси, сетка, полилиния — без SkiaSharp/ScottPlot)
- .NET Framework 4.8 → **.NET 10**; работает на Windows, macOS и Linux

### Оптимизации
- F#: наивная рекурсия `let rec Get n = Get (n-1) + Get (n-2)` — **O(φⁿ)**;
  заменена на итеративное вычисление **O(n)** (1000 вызовов Get(30) ≈ 0.2 мс)
- Presenter: 4 копипастных метода (Sin/Cos/Parabola/Line) → один параметризованный
- Min/max по сетке: O(n²) (FindMax/FindMin на каждую добавленную точку) → один проход O(n)
- Отрисовка графика не зависит от шага H: 1001 точка на интервал — кривая
  всегда гладкая; H используется только для расчёта min/max

### Правильность и UX
- Классическая корректная схема метода Фибоначчи (в старой — недостижимая
  ветка `elif` и квазиалгоритм со смещёнными индексами)
- Обработка некорректного ввода: B < A — границы меняются местами; A = B —
  интервал по умолчанию; H/ε ≤ 0 — подстановка дефолтов; каждое событие
  видно в статус-баре (появляется только с сообщением)
- Любые исключения модели перехватываются — приложение не падает
- Панель результатов и кнопки не скроллятся и не обрезаются; панель параметров
  сворачивается (SplitView, кнопка-гамбургер)
- MVP-паттерн честный: Presenter зависит только от `IExtremumView`

## Запуск

```bash
dotnet run --project MVPGraph
```

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

## Сборка

```bash
dotnet publish MVPGraph -c Release
```

Бинарь для вашей платформы появится в `MVPGraph/bin/Release/net10.0/publish/`.

## Структура

```
FMath/            F#: числа Фибоначчи (O(n)) + элементарные функции
MVPGraph/
  Model/          метод Фибоначчи (поиск min/max унимодальной функции)
  Presenter/      связывание модели и вида (без зависимостей от UI)
  View/           IExtremumView, FunctionChart (график), окно
Jupyter/          ноутбук с выкладками метода (исходный артефакт)
```
